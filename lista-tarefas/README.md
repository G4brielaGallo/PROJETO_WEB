# Lista de Tarefas

Aplicação web para organização e acompanhamento de tarefas pessoais, com prazo e descrição.

## Sobre o projeto
O projeto consiste em uma lista de tarefas executada inteiramente no navegador. O usuário cadastra tarefas com nome, prazo e descrição, marca como concluídas, reabre ou remove, acompanhando o total de tarefas.

## Funcionalidades
- Cadastro de tarefas com nome, prazo e descrição
- Validação: campos obrigatórios, descrição com no mínimo 3 caracteres e prazo não anterior à data de hoje
- Marcar tarefa como concluída e reabri-la
- Remoção de tarefas
- Contador com o total de tarefas

As tarefas ficam apenas na página aberta: ao recarregar, a lista é perdida.
