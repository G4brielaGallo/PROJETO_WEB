# PROJETO_WEB

Coleção de projetos web desenvolvidos durante o curso de Desenvolvimento de Sistemas (ETEC). Cada pasta está organizada para ser publicada como um repositório próprio no GitHub, seguindo o *Roteiro para Organização de um Projeto no GitHub*.

## Projetos

| Pasta | Descrição para o GitHub | Tecnologias |
|---|---|---|
| `loja-carrinho-compras` | Loja virtual de livros com filtro por preço e carrinho de compras. | HTML, CSS, JavaScript, Bootstrap |
| `sistema-notas-turma` | Sistema que calcula médias, situação dos alunos e estatísticas de uma turma. | PHP, HTML, CSS |
| `lista-tarefas` | Aplicação para organização e acompanhamento de tarefas pessoais. | HTML, CSS, JavaScript |
| `site-pessoal-gabriela` | Site pessoal e portfólio acadêmico com os trabalhos do curso. | HTML, CSS |
| `gerenciador-mundo` | Sistema CRUD de países, cidades, continentes e governantes com controle de acesso. | PHP, MySQL, HTML, CSS |

Cada projeto contém `README.md`, `.gitignore`, `LICENSE` e seu código organizado em pastas (`src/`, `assets/`, `database/`, `docs/`, conforme o caso).
