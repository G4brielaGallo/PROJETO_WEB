# Site Pessoal - Gabriela Gallo

Site pessoal e portfólio acadêmico de uma estudante de Desenvolvimento de Sistemas, reunindo apresentação pessoal e os trabalhos desenvolvidos ao longo do curso.

## Sobre o projeto
O site apresenta quem é a autora, sua história e seus hobbies, e conta com uma página acadêmica que organiza, por ano e disciplina, os trabalhos, diagramas e projetos realizados na ETEC.

## Funcionalidades
- Página inicial com as seções Sobre Mim, História e Hobbies
- Navegação por âncoras entre as seções
- Página Acadêmico com trabalhos organizados por ano e disciplina
- Imagens de diagramas e fotos dos trabalhos
- Links para download dos projetos desenvolvidos

## Tecnologias utilizadas
- HTML
- CSS
- Git
- GitHub

## Estrutura do projeto
```
site-pessoal-gabriela/
├── assets/
│   ├── css/estilos.css      # Estilos do site
│   └── img/pessoal/         # Fotos usadas na página inicial

│   └── 2oAno/               # Trabalhos do 2º ano, por disciplina

├── academico.html           # Página acadêmica
├── README.md
├── LICENSE
└── .gitignore
```

## Requisitos
- Navegador atualizado

## Como executar
1. Clone o repositório.
2. Abra o arquivo `index.html` no navegador.

## Observação
O arquivo `docs/1oAno/DD/Mystic.zip` tem cerca de 100 MB, o limite de arquivo do GitHub. Para publicá-lo, use o Git LFS ou hospede o arquivo externamente (por exemplo, no Google Drive) e atualize o link em `academico.html`.
